## PACE v0.1 · 本地运动数据分析

第一个公开版本。PACE 是一个**纯本地**的骑行/跑步数据分析仪表盘 + 教练：后端只用 Python 3.11+ 标准库（零第三方依赖），前端原生 JS 无构建步骤，数据存 SQLite 单文件，不上传任何东西。

### 包含什么

- **导入**：GPX / FIT（含 .fit.gz）/ TCX / CSV 拖进网页即解析；支持 iGPSPORT 码表 USB 与文件夹、华为运动健康导出、Intervals.icu、Strava 官方 API
- **分析**：配速与心率区间、训练负荷（CTL/ATL/TSB）、分段与个人纪录、相同路段对比、海拔剖面、爬坡分级
- **教练**：按目标与每周天数生成多周期计划（跑步 5 种目标、骑行 5 种、游泳 4 种），带护栏与风险提示
- **路书**：搜索地点 → 地图上确认坐标 → Valhalla/OSRM 规划、超过 10 个点自动分段、爬坡识别与 HC/1–4 级分类、点爬坡在地图上定位（保持缩放）
- **离线降级**：拿不到地图瓦片时自动画抽象轨迹图，仍可查看与回放

### 运行

需要 Python 3.11+，不需要 pip install：

```bash
python run.py            # 或双击 启动PACE.bat
```

打开 http://127.0.0.1:8765 。想先看点数据：`python run.py --seed-demo`（样例在 `sample-data/`）。

### 附件

- `pace-v0.1-src.zip`：源码包（不含任何个人数据、数据库或令牌）

### 已知限制

- 免费 OSM 数据在国内细节一般：POI 落在「客运站 / 院区」这类院内点位时，骑行路线可能绕一圈再出来；目前给「绕行偏多」提示，彻底解决需要接高德 Web 服务 Key
- 地图瓦片在线拉取，断网时降级为抽象轨迹图
- 单人本地使用，没有账号体系，也没有多端同步
