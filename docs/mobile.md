# 手机上用 PACE

PACE 是「电脑上跑服务、手机用浏览器打开」，数据始终在电脑里。下面三种方式按推荐度排。

## 方案 A：同一个 WiFi（推荐，免费、最稳、零延迟）

1. 双击 **`启动PACE-手机.bat`**（或命令行 `python run.py --host 0.0.0.0`）
2. 窗口里会打印两行地址，看「手机」那行，比如 `http://192.168.3.22:8765/`
3. 手机连**同一个 WiFi**，浏览器打开这个地址
4. 首次会弹 Windows 防火墙提示 → 勾选「专用网络」→ 允许

**装成 App 的样子**：手机浏览器菜单 →「添加到主屏幕」（iOS Safari 是分享 → 添加到主屏幕）。
打开后是全屏无地址栏，图标是 PACE。

注意：电脑关机/休眠、或换到别的 WiFi，手机就连不上。

## 方案 B：在外面也能用 —— Tailscale（免费、稳定、最推荐的外网方案）

不需要买服务器、不用域名、不用公网端口。

1. 电脑装 Tailscale 并登录（免费个人版够用）
2. 手机装 Tailscale App，登**同一个账号**
3. 电脑的 Tailscale 面板里能看到它的 IP（`100.x.x.x`）
4. 电脑上跑 `python run.py --host 0.0.0.0`
5. 手机在任何网络下打开 `http://100.x.x.x:8765`

优点：只有你自己的设备能进（私有网络），不暴露在公网，速度取决于两台设备的网络质量。
缺点：手机和电脑都要开着 Tailscale。

## 方案 C：临时给朋友看 —— Cloudflare 临时隧道（免费，地址会变）

```powershell
# 装 cloudflared 后：
cloudflared tunnel --url http://localhost:8765
```

会给你一个 `https://xxx.trycloudflare.com` 地址，电脑关掉就失效，每次重启地址都会变。
适合临时演示，不适合长期给朋友用（而且明文密码风险仍在，好在 CF 这段是 HTTPS）。

## 常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开 | 确认同一个 WiFi；Windows 防火墙放行 Python（专用网络） |
| 打开很慢 | 首次加载约 120 KB，之后走缓存；WiFi 差就等两秒 |
| 想换端口 | `python run.py --host 0.0.0.0 --port 9000` |
| 手机上导入 GPX | 手机上点「导入活动」，选文件即可，数据存回电脑的库 |
| 睡前想关电脑 | 手机访问就断了；想随时用就选方案 B 或买服务器 |
